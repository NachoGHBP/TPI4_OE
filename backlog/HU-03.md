# HU-03 · Consultar reportes para tomar decisiones

Como administrativo, quiero consultar alumnos activos y asistencia por período, para entregar a coordinación información que permita revisar horarios, cupos y participación.

## Criterios de aceptación

- [ ] HU-03-CA1. Dado un período válido, el reporte de alumnos activos usa ALUMNO.activo y el de asistencia filtra por fecha de SESION; no confunde ambos conceptos.
- [ ] HU-03-CA2. Dadas sesiones realizadas, calcula presentes, ausentes confirmados y pendientes sobre las participaciones esperadas de inscripciones vigentes. Excluye sesiones canceladas.
- [ ] HU-03-CA3. Dados pendientes, identifica el porcentaje como provisional. Con denominador cero muestra “sin participaciones esperadas”. El instructor solo accede a sus clases.
